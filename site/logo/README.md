# Logo Folder

Place your logo image file in this folder.

**Supported formats:** PNG, JPG, JPEG, SVG, WEBP

**Recommended:** A square image (e.g., 200x200px or 400x400px) works best.

**How to use:**
1. Add your logo file to this folder (e.g., `logo.png`)
2. Open `index.html`
3. Find the `<img>` tag inside `<div class="logo-container">` and update the `src` attribute to match your filename:

```html
<img src="logo/your-logo-filename.png" alt="Logo" class="logo-img" />
```

By default, the site is set to look for `logo/logo.png`.
